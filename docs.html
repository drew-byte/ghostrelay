Query Reference

Field names, operators, syntax, and event ID reference for the GhostRelay SIEM.

Index & Data Model

All log data lives in a single index pattern: ghost-relay-*. The index contains 1,551 documents spanning three days. Each document is a normalized Windows event with a flat field structure — no nested objects.

Source logs come from three Windows channels, normalized into a common schema:

ChannelSourceEvent IDs
Microsoft-Windows-Sysmon/OperationalSysmon agent1, 3, 10, 11, 22
SecurityWindows Security Audit4624, 4648, 4688
SystemWindows System7045

Interface Layout

The SIEM has three main zones:

  • Top bar — index selector, document count, time range
  • Query bar — KQL input, Run button, saved search shortcuts
  • Left panel — live facet counts for event_id, host, user. Click any facet value to append it to the current query.
  • Histogram — event density over time for the current result set
  • Results table — sortable columns, 50 rows per page
  • Detail drawer — click any row to expand all fields for that document
Facet click behavior: Clicking a facet value in the left panel appends field: "value" to whatever is currently in the query bar using AND. This lets you drill down incrementally without retyping.

KQL Syntax

The query bar accepts KQL (Kibana Query Language). Queries are case-insensitive. Press Enter or click ▶ Search to execute.

Basic field match

# Exact match — quotes required for multi-word values or special chars
event_id: "1"
host: "WORKSTATION-03"
granted_access: "0x1FFFFF"
dst_port: "443"

Wildcard match

# * matches any sequence of characters
command_line: *powershell*
image: *lsass*
user: *jmendoza*
target_filename: *Temp*

# Prefix wildcard — ends with
image: *cmd.exe

# Suffix wildcard — starts with
target_filename: C:\Windows\Temp\*

Boolean combinations

# AND — both conditions must match
event_id: "1" AND host: "WORKSTATION-03"

# Multiple AND conditions
event_id: "3" AND dst_port: "443" AND host: "WORKSTATION-03"

Free-text search

# No field prefix — searches all fields
psexec
185.220.101.47
lsass
PSEXESVC

Operators

SyntaxBehaviorExample
field: "value" Exact match, case-insensitive event_id: "10"
field: *value* Contains substring (wildcard both sides) command_line: *encoded*
field: value* Starts with prefix image: C:\Windows\Temp\*
field: *value Ends with suffix image: *powershell.exe
field: value Contains (no quotes, no wildcard) host: WORKSTATION
AND Both clauses must match event_id: "1" AND user: *jmendoza*
(no prefix) Full-document text search psexec64
Note: OR and NOT are not supported in this implementation. To search for multiple values of the same field, run separate queries or use a broad wildcard and refine with additional AND conditions.

Wildcards

The * character matches any sequence of characters including none. It can appear at the start, end, or both sides of a value.

# Match any file in Temp directory
target_filename: *\Temp\*

# Match any .exe dropped in Temp
target_filename: *\Temp\*.exe

# Match any process whose name ends with cmd.exe (catches full paths)
image: *cmd.exe

# Match encoded command flag variants (-Enc, -EncodedCommand)
command_line: *-Enc*

# Match any user in the CORP domain
user: CORP\*

Boolean Logic

Use AND (uppercase) to combine multiple field conditions. All conditions must be true for a document to match.

# Two conditions
event_id: "1" AND user: *jmendoza*

# Three conditions
event_id: "3" AND dst_ip: "185.220.101.47" AND dst_port: "443"

# Mix exact and wildcard
event_id: "11" AND host: "WORKSTATION-03" AND target_filename: *\Temp\*

# Narrow by channel and event type
channel: *Security* AND event_id: "4624" AND logon_type: "3"

Query Examples

Process creation

# All process creation events
event_id: "1"

# Process creation on a specific host
event_id: "1" AND host: "WORKSTATION-03"

# Find processes spawned by a specific parent
event_id: "1" AND parent_image: *WINWORD*

# Command lines containing a specific flag
event_id: "1" AND command_line: *-Enc*

# Processes run by a specific user
event_id: "1" AND user: *jmendoza*

# Processes with a specific executable name (anywhere in path)
event_id: "1" AND image: *net.exe

Network connections

# All network connection events
event_id: "3"

# Connections to a specific IP
event_id: "3" AND dst_ip: "185.220.101.47"

# Connections on port 443 from a specific host
event_id: "3" AND dst_port: "443" AND host: "WORKSTATION-03"

# Network connections from PowerShell
event_id: "3" AND image: *powershell*

File creation

# All file creation events
event_id: "11"

# Files created in Windows Temp
event_id: "11" AND target_filename: *\Temp\*

# Specific file extension
event_id: "11" AND target_filename: *.exe

# Files created by a specific process
event_id: "11" AND image: *powershell*

DNS queries

# All DNS query events
event_id: "22"

# DNS from a specific host
event_id: "22" AND host: "WORKSTATION-03"

# Specific domain query
event_id: "22" AND dns_query: "xk3r9v2malpq.net"

# DNS queries that returned NXDOMAIN
event_id: "22" AND dns_result: *NXDOMAIN*

# DNS queries from PowerShell specifically
event_id: "22" AND image: *powershell*

Process access (EID 10)

# All process access events
event_id: "10"

# Access with a specific access mask
event_id: "10" AND granted_access: "0x1FFFFF"

# Access targeting a specific process
event_id: "10" AND target_image: *lsass*

Authentication events

# Successful logons
event_id: "4624"

# Network logons only (logon type 3)
event_id: "4624" AND logon_type: "3"

# Logons for a specific user
event_id: "4624" AND user: *jmendoza*

# Explicit credential logons
event_id: "4648"

# Service installations
event_id: "7045"

Cross-field correlation

# All events on a host for a user
host: "WORKSTATION-03" AND user: *jmendoza*

# EID 11 on specific host by specific user
event_id: "11" AND host: "WORKSTATION-03" AND user: *jmendoza*

# Combine channel filter with event type
channel: *Sysmon* AND event_id: "1" AND host: "WORKSTATION-07"

Sysmon Event IDs

1
Process Creation
Fires every time a new process starts. Contains the full executable path, command line, parent process, user context, and file hashes. The parent_image field establishes the process tree.
image · command_line · parent_image · hashes · process_guid · integrity_level
3
Network Connection
Fires for each outbound TCP/UDP connection. Records the initiating process, source and destination endpoints. Only logs initiated (outbound) connections by default.
image · dst_ip · dst_port · src_ip · src_port · protocol
10
Process Access
Fires when a process opens a handle to another process using OpenProcess(). The granted_access field contains the access mask. source_image is the opener, target_image is the target.
source_image · target_image · granted_access
11
File Created
Fires when a file is created or overwritten on disk. The target_filename is the full path of the new file. image is the process that wrote it.
image · target_filename · user
22
DNS Query
Fires for every DNS lookup. dns_query is the queried name. dns_result contains the response — IP for A records, NXDOMAIN for non-existent domains.
dns_query · dns_result · image

Windows Security Event IDs

4624
An account was successfully logged on
Generated for every successful authentication. The logon_type field describes how the logon occurred. src_ip shows the originating address for network logons.
user · logon_type · src_ip · logon_id
4648
A logon was attempted using explicit credentials
Generated when a process explicitly supplies credentials — such as runas, or tools using /user: flags. The service_name field holds the target server name.
user · image · service_name · src_ip
4688
A new process has been created
Windows built-in equivalent of Sysmon EID 1. Enabled via audit policy. Contains command line and parent process name but no file hashes. Less detailed than EID 1 but present in the Security channel.
image · command_line · parent_image · user

Windows System Event IDs

7045
A new service was installed in the system
Generated in the System channel when the Service Control Manager registers a new service. Contains the service name, binary path, start type, and account. Logged on the host where the service is installed.
service_name · image_path · user

Log Channels

The channel field identifies which Windows event log the document originated from. Use this to restrict searches to a specific log source.

# Sysmon events only
channel: *Sysmon*

# Windows Security events only
channel: "Security"

# Windows System events only
channel: "System"
